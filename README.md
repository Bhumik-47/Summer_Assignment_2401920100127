# ☀️ DSA & OOPs Summer Assignment Repository 🚀

Welcome to my Summer Assignment repository. This space is dedicated to documenting my technical growth, algorithmic problem-solving on LeetCode, and practical Object-Oriented Programming (OOP) implementations over the summer break.

---

## 📌 Project Overview

The objective of this assignment is dual-focused: building a rock-solid foundation in core data structures while consistently reinforcing software engineering principles through object-oriented design.

* **DSA Platform:** LeetCode
* **OOPs Cadence:** 1 Comprehensive Challenge per week
* **Core Focus:** Code optimization, memory management, modular design, and scalability.

---

## 🛠️ Key Modules Covered

### 1. Data Structures & Algorithms (DSA)
Focuses on transitioning from brute-force methods to optimized solutions across fundamental topics:
* **Linear & Non-Linear Structures:** Arrays, Linked Lists, Stacks, Queues, Trees, and Graphs.
* **Algorithmic Techniques:** Two Pointers, Sliding Window, Binary Search, and Dynamic Programming.

### 2. Object-Oriented Programming (OOP)
A weekly deep-dive into creating robust, real-world software blueprints by leveraging the four pillars of OOPs:
* **Encapsulation & Abstraction:** Data hiding and exposing only essential features via clean interfaces.
* **Inheritance & Polymorphism:** Maximizing code reusability and implementing dynamic, runtime flexibility.

---

## 💡 Methodology & Workflow

For both DSA and OOPs challenges, the implementation workflow ensures high-quality submissions:
1. **Analysis:** Reviewing constraints, edge cases, and architectural requirements.
2. **Optimization:** Targeting ideal Time and Space complexities ($O(1)$, $O(N)$, or $O(\log N)$).
3. **Design Patterns:** Applying clean, modular, and dry (Don't Repeat Yourself) code structures for weekly OOPs tasks.
